# 🎓 AI StudyBuddy

An AI-powered backend that helps students study smarter. Upload study material and get summaries, flashcards, quizzes, and personalized study plans.

## 📌 Project Overview

AI StudyBuddy uses the Google Gemini AI API to turn study material into learning resources. Students register, log in, add their notes, and pick what they want the AI to generate. Everything is saved so they can revise later.

## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB and Mongoose
- JWT authentication
- bcryptjs
- Multer (file upload)
- Google Gemini AI

## ✨ Features

- Secure register and login
- Upload and manage study materials
- AI summary generation
- AI flashcard generation
- AI quiz generation
- AI study plan generation
- Admin access to manage users

## 🚀 How to Run

1. Run `npm install`
2. Copy `.env.example` to `.env` and fill in your values
3. Run `npm start`
